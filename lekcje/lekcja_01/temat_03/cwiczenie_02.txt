AKTUALNA BAZA PO TEMACIE 7
Obecna wersja projektu korzysta z MariaDB. Włącz MySQL w XAMPP.
W phpMyAdmin (http://localhost/phpmyadmin) utwórz bazę poleceniem SQL:
CREATE DATABASE IF NOT EXISTS project CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
W lokalnym .env sprawdź wartości (dostosuj konto, hasło i port do uczelni):
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=project
DB_USERNAME=root
DB_PASSWORD=
Nowy .env.example zawiera te ustawienia. W istniejącym .env zmień stare DB_*.
Po zmianie konfiguracji wykonaj php artisan config:clear i php artisan migrate.
Apache jest potrzebny do phpMyAdmin; aplikację możesz uruchamiać przez Artisan.

POBRANIE I PIERWSZE URUCHOMIENIE NA UCZELNI
1. Wymagane: XAMPP z PHP 8.2 lub nowszym oraz Composer.
2. Otwórz https://github.com/pzx119592/WSB_ZastProg
   Kliknij Code -> Download ZIP i rozpakuj archiwum.
3. Skopiuj folder project_1 do C:\xampp\htdocs.
   Zachowaj kopię istniejącego projektu przed zastąpieniem.
4. W PowerShell wykonaj:

cd C:\xampp\htdocs\project_1
$env:Path = "C:\xampp\php;" + $env:Path
composer install
if (!(Test-Path .env)) { Copy-Item .env.example .env }
php artisan key:generate
php artisan migrate
php artisan serve --host=127.0.0.1 --port=8000

Przy kolejnym uruchomieniu wystarczy wejść do folderu projektu i uruchomić Artisan.
Terminal serwera pozostaw otwarty; Ctrl+C zatrzymuje serwer.
Przy zajętym porcie użyj --port=8001 i odpowiednio zmień adres w przeglądarce.
Jeśli XAMPP ma inną lokalizację, dostosuj ścieżki.
Do aplikacji potrzebne są Artisan i MariaDB; Apache i npm nie są wymagane.

JAK TO DZIAŁA
/witaj korzysta z funkcji anonimowej (Closure).
/test wywołuje TestController::index.
Kontroler wygenerowano: php artisan make:controller TestController.

Lista tras: php artisan route:list --except-vendor
