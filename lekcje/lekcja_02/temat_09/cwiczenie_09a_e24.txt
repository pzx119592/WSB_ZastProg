POBRANIE I URUCHOMIENIE NA UCZELNI
1. Wymagane: XAMPP z PHP 8.2+, Composer, MariaDB. Włącz MySQL w XAMPP.
   Dla phpMyAdmin uruchom również Apache.
2. https://github.com/pzx119592/WSB_ZastProg -> Code -> Download ZIP.
   Rozpakuj, skopiuj project_1 do C:\xampp\htdocs.
   Przed aktualizacją zachowaj kopię swoich istniejących plików.
3. http://localhost/phpmyadmin -> SQL:
   CREATE DATABASE IF NOT EXISTS project CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
4. PowerShell:

cd C:\xampp\htdocs\project_1
$env:Path = "C:\xampp\php;" + $env:Path
composer install
if (!(Test-Path .env)) { Copy-Item .env.example .env }

5. Dla nowego .env wykonaj php artisan key:generate. Przy aktualizacji zachowaj
   istniejący APP_KEY. Sprawdź połączenie w .env:
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=project
DB_USERNAME=root
DB_PASSWORD=

Dostosuj hasło, konto, port i bazę do komputera uczelnianego.
6. Dalej w terminalu:

php artisan config:clear
php artisan migrate
php artisan db:seed --class=BookSeeder
php artisan serve --host=127.0.0.1 --port=8000

Terminal serwera pozostaw otwarty; Ctrl+C go zatrzymuje.
Przy kolejnym uruchomieniu włącz MariaDB i wykonaj artisan serve.
Przy zajętym porcie wybierz --port=8001 i zmień adres w przeglądarce.
Nie potrzeba npm ani Node.js. composer install odtwarza zależności z composer.lock.
Nie używaj migrate:fresh — usuwa istniejące tabele i dane innych ćwiczeń.

ARTISAN UŻYTY W ĆWICZENIU
php artisan make:model Book
php artisan make:controller BookController
php artisan make:migration create_books_temat9_table --create=books_temat9
php artisan make:seeder BookSeeder

Na uczelni nie generuj ich ponownie: pliki już są w pobranym projekcie.
Dodatkowe opcje make:model (do wyjaśnienia, nie do nadpisywania plików):
-m lub --migration: model i migracja.
-c lub --controller: także kontroler.
-s lub --seed: także seeder.
-f lub --factory: także fabryka danych testowych.
-r lub --resource: kontroler zasobu z metodami CRUD (razem z -c).
-a lub --all: model i komplet powiązanych klas.
Można je łączyć, np. php artisan make:model Przyklad -mcs.
Pomoc: php artisan help make:model.

ZAPYTANIA PRZEZ MODEL — DO WYJAŚNIENIA
Book::all() — pobierz wszystkie książki modelu Book.
Book::where('year', '>=', 1886)->get() — pobierz książki spełniające warunek.
Book::find(1) — pobierz książkę o id 1.
Model odwołuje się tu do books_temat9; Eloquent bez $table wybrałby books.
Kontroler pobiera modele, przekazuje je do widoku, a Blade wyświetla tytuły.
