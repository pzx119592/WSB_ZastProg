PHP / XAMPP / Laravel 12. Instrukcja dotyczy Windows i pierwszego uruchomienia.

1. ZAINSTALUJ ŚRODOWISKO (TYLKO RAZ)
-----------------------------------
XAMPP: https://www.apachefriends.org/download.html
Wybierz wydanie Windows z PHP 8.2 lub nowszym. Zainstaluj w C:\xampp.
Potrzebujesz Apache, PHP, MariaDB (w panelu: MySQL) i phpMyAdmin.
Composer: https://getcomposer.org/download/
W instalatorze wskaż interpreter C:\xampp\php\php.exe.
VS Code jest przydatny do pokazania kodu, ale nie jest potrzebny do uruchomienia.
Git jest potrzebny tylko do wariantu git clone i pokazania historii commitów.

Otwórz NOWE okno PowerShell i wykonaj:
$env:Path = "C:\xampp\php;" + $env:Path
php --version
composer --version
php --ini

PHP musi mieć wersję co najmniej 8.2, a konfiguracja pochodzić z XAMPP.
W C:\xampp\php\php.ini sprawdź rozszerzenia curl, mbstring, openssl, pdo_mysql,
fileinfo i zip. Do testów potrzebne jest też pdo_sqlite. W razie potrzeby usuń
średnik przed istniejącą linią extension=..., zapisz i zrestartuj Apache.
Nie trzeba instalować Laravel od nowa ani uruchamiać laravel new.
Nie potrzeba Node.js, npm ani kopiowania całego folderu C:\xampp ze starego PC.

2. POBIERZ CAŁE REPOZYTORIUM I UŁÓŻ FOLDERY
------------------------------------------
GitHub -> zielony przycisk Code -> Download ZIP -> rozpakuj archiwum.
Folder WSB_ZastProg-main przemianuj na project1 i umieść w:
C:\xampp\htdocs\git\project1
W środku mają być README.md, index.php, project_1, pierwszy_skrypt, baza, lekcje.
Uważaj na podwójny folder, np. project1\WSB_ZastProg-main\project_1.

Następnie z tego pobranego folderu skopiuj:
- project_1 -> C:\xampp\htdocs\project_1
- pierwszy_skrypt -> C:\xampp\htdocs\pierwszy_skrypt

Docelowe pliki:
C:\xampp\htdocs\project_1\artisan
C:\xampp\htdocs\pierwszy_skrypt\index.php
C:\xampp\htdocs\git\project1\index.php

Jeśli te katalogi już istnieją i zawierają Twoje pliki, zachowaj ich kopię
przed podmianą. Dalej pracujemy w C:\xampp\htdocs\project_1.

ALTERNATYWA Z GIT (ZAMIAST ZIP)
Po instalacji Git, gdy folder project1 jeszcze nie istnieje:
git clone https://github.com/pzx119592/WSB_ZastProg.git C:\xampp\htdocs\git\project1
Następnie skopiuj project_1 i pierwszy_skrypt tak samo jak powyżej.
Git clone pobiera również historię commitów; ZIP zawiera tylko pliki.
Publiczne repozytorium można pobrać bez logowania do GitHuba.

3. PRZYGOTUJ LARAVEL
-------------------
W PowerShell wykonaj:
cd C:\xampp\htdocs\project_1
$env:Path = "C:\xampp\php;" + $env:Path
Copy-Item .env.example .env
composer install
composer check-platform-reqs
php artisan key:generate
php artisan --version

Powinno być Laravel Framework 12.x. Używaj composer install: composer.lock
odtwarza wersje bibliotek z repozytorium. Nie wykonuj composer update.
composer install automatycznie instaluje też pliki CSS/JS panelu AdminLTE.
Kopiowanie .env.example i generowanie klucza wykonaj tylko dla NOWEJ instalacji.

4. UTWÓRZ BAZĘ I USTAW .env
--------------------------
W XAMPP uruchom Apache i MySQL. Otwórz http://localhost/phpmyadmin.
Utwórz NOWĄ pustą bazę project, kodowanie utf8mb4_unicode_ci.
Jeśli project już zawiera cudze lub własne dane, użyj nowej bazy, np.
project_kurs, i wpisz tę samą nazwę w DB_DATABASE poniżej.

W pliku C:\xampp\htdocs\project_1\.env ustaw:
APP_URL=http://127.0.0.1:8000
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=project
DB_USERNAME=root
DB_PASSWORD=

Puste hasło dotyczy standardowej lokalnej instalacji XAMPP. Jeżeli na drugim
komputerze jest inne konto, hasło lub port MariaDB, wpisz jego właściwe dane.
Zostaw SESSION_DRIVER=database i CACHE_STORE=database z .env.example.

5. ODTWÓRZ STRUKTURĘ I DANE PRZYKŁADOWE (WARIANT Z GITHUBA)
----------------------------------------------------------
W terminalu projektu:
php artisan config:clear
php artisan migrate

W phpMyAdmin wybierz nową bazę -> Import i wgraj kolejno:
C:\xampp\htdocs\git\project1\baza\temat_07_dane_przykladowe.sql
C:\xampp\htdocs\git\project1\baza\temat_09_dane_przykladowe.sql
Format SQL, kodowanie UTF-8. Każdy plik importuj RAZ, do pustych tabel.

Oczekiwane dane: user — 1 osoba, books — 11 książek, books_temat9 — 3 książki,
tests — 1 osoba. Tabela users (konta logowania) będzie na razie pusta.
W terminalu wykonaj następnie:
php artisan db:seed --class=BooksTableSeeder --check="The Catcher in the Rye"

Komunikat o istniejącej książce jest tu oczekiwanym wynikiem ćwiczenia 7B.
Po tych importach nie uruchamiaj zwykłych seederów BooksTableSeeder/BookSeeder
ani ogólnego db:seed: dane do prezentacji zostały już odtworzone.
Nie używaj migrate:fresh ani migrate:refresh — usuwają dane.

6. URUCHOM I UTWÓRZ KONTO
------------------------
php artisan serve --host=127.0.0.1 --port=8000

Pozostaw terminal otwarty. Otwórz http://127.0.0.1:8000/.
Wszystkie linki są pod nagłówkami odpowiednich tematów.
Otwórz /register, utwórz własne konto, a potem zaloguj się przez /login.
Konta i hasła ze starego komputera nie są częścią publicznego zestawu SQL.
Panel i jego logo powinny wyglądać tak samo. Użyj jednego adresu bazowego
(127.0.0.1:8000) podczas rejestracji, logowania i korzystania z panelu.

10. NAJCZĘSTSZE PROBLEMY
-----------------------
"php/composer nie jest rozpoznawane": nowe okno PowerShell, dopisz PHP do Path
poleceniem z kroku 1; Composer musi być zainstalowany i wskazywać PHP XAMPP.
Brak vendor/autoload.php: wykonaj composer install w folderze project_1.
Brak APP_KEY: php artisan key:generate dla nowej instalacji.
Unknown database / Connection refused: włącz MySQL, sprawdź bazę i dane .env.
Brak tabel sessions/cache: wykonaj php artisan migrate w właściwej bazie.
Błąd 419: odśwież formularz, używaj tego samego adresu bazowego i sprawdź sesje.
Zajęty port 8000: php artisan serve --port=8001, używaj wtedy 127.0.0.1:8001.
Brak wyglądu panelu: composer install; ewentualnie:
php artisan adminlte:install --only=assets --no-interaction
NBP niedostępne: sprawdź Internet i komunikat aplikacji. Przy błędzie certyfikatu
nie wyłączaj weryfikacji HTTPS; trzeba poprawić certyfikaty CA w PHP.
Brak zmian po edycji .env/widoków: php artisan config:clear i php artisan view:clear.
